# TRANSPARENCY STATEMENT REGARDING PRE-EXISTING WORK

## Previous Stage — July 2026

In July 2026, following an invitation to participate in an earlier competition, I attempted for the first time to transform my own way of working with AI into a demonstrable project.

At that stage, I used the name HUMAN VECTOR for the first time.

However, the July project was much more limited than HUMAN VECTOR in its current form. It contained only a few basic principles, focused mainly on:

- contradiction between the HUMAN position and the AI response;
- repeated verification of the AI response;
- not automatically accepting the first response;
- preserving the final decision with the HUMAN.

These principles came from my actual way of working with AI: using the AI response as material for verification, contradiction, and reconstruction rather than as a result that should automatically be accepted.

Because of the very limited time available, I was unable to complete and submit the entire project prepared at that time. There was a partial submission and a video, but that project did not contain the architecture, principles, agents, or technical implementation of the current HUMAN VECTOR.

The relevant elements carried forward from that stage are the HUMAN VECTOR name and the initial core idea of HUMAN–AI contradiction and critical verification.

## August 1–2, 2026 — Technical Prototype for CockroachDB × AWS

On August 1, 2026, I began the practical development of a new prototype for:

This work began before the official period relevant to All Things Agentic and is explicitly disclosed as pre-existing work.

- configuring CockroachDB Cloud;

- installing and testing the PostgreSQL driver;
- verifying database connectivity and persistence;
- initial preparation of the AWS infrastructure.

This prototype did not use Gemini, Google ADK, or Google Cloud and had not been built for The Collaborative Partner track.
