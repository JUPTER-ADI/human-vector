# Originality and Positioning

## 1. Positioning statement

**HUMAN VECTOR is a human-directed protocol and application for producing stronger solutions while making the human's critical, selective, and decision-making work visible and necessary.** It combines independently traceable agent threads, explicit human-controlled information transfer, designed contradiction, cognitive provenance, persistent memory with demonstrated influence, and separate assessment of solution improvement and observable human process.

The project is not positioned as “an autonomous agent that asks for approval.” Its center is the human's continuing authority and the protocol evidence that authority was exercised.

## 2. What is not an originality claim

No originality is claimed merely from using multiple agents, model roles, memory, retrieval-augmented generation, orchestration, human approval, persistent state, audit logs, or version comparison. These are established patterns or enabling components. “Human in the loop” alone is too broad and often describes a final checkpoint rather than human direction throughout.

## 3. Combined differentiating structure

The defensible project contribution is the integration and operationalization of:

1. genuinely separate builder, critic, and optional specialist threads with inspectable input manifests;
2. human-controlled, item-level transfer rather than invisible shared context;
3. controlled contradiction that challenges both AI output and human contribution without usurping direction;
4. an explicit place for human-generated ideas not proposed by an AI thread;
5. element-level cognitive provenance preserving accepted, rejected, and reconstructed origins;
6. persistent memory whose pre-generation use and visible effect are evidenced;
7. simultaneous but separate evaluation of solution quality and observable human process;
8. anti-overreliance mechanics that require critique, justification, verification, and final human decision.

The combination matters only if enforced in application state. Labels and explanatory diagrams do not establish differentiation.

## 4. Category contrasts

| Adjacent pattern | Typical center | HUMAN VECTOR distinction |
|---|---|---|
| Multi-agent orchestration | Agents coordinate to optimize task completion | Context transfer is human-authorized; agent coordination cannot silently bypass the human |
| Debate/critic systems | Models critique or vote to improve an answer | Contradiction must provoke a recorded human response; no AI vote decides |
| RAG/memory assistants | Retrieve context to improve continuity | Used memories are inspectable, disposition-aware, linked before generation, and traced into reconstruction |
| Human approval workflows | Human approves an AI-produced result | Human establishes direction, contributes, critiques, transfers, verifies, reconstructs, and decides |
| Audit/version tools | Record changes and actors | Provenance tracks idea origin, rejection, transfer, context inclusion, and authority-bearing decisions |
| Educational/cognitive tools | Teach or score a learner | No diagnosis or automatic education claim; only bounded process observations and indicators |

These are conceptual contrasts, not claims that every product in a category behaves identically.

## 5. Claims ladder

Claims should advance only with evidence:

- **Protocol claim:** the specification assigns authority and defines traceability. Evidence: documents and invariant mapping.
- **Implementation claim:** the application enforces the rules. Evidence: state, manifests, negative tests, and persisted records.
- **Demonstration claim:** one fictional run shows solution and process differences. Evidence: predefined rubric and complete provenance.
- **Usability claim:** people can understand and use the flow. Requires user evaluation.
- **General human-development or causal claim:** outside MVP scope and requires an appropriate external research design.

The project MUST NOT jump from protocol or demo evidence to scientific or population claims.

## 6. Recommended public language

Use:

- “human-directed agentic memory”;
- “AI creates structured pressure and alternatives; the human retains authority”;
- “the demo records observable critical and verification actions”;
- “memory influence is linked to reconstruction inputs”;
- “the final decision is explicitly human.”

Avoid:

- “the AI improves human cognition”;
- “fully autonomous” or “AI decides”;
- “bias-free,” “guaranteed correct,” or “proves originality”;
- “independent critic” when context manifests do not establish independence;
- “memory-powered” when retrieved records are only displayed post hoc.

## 7. Originality validation work

Before making formal novelty claims, conduct and date a landscape review of academic work, patents where relevant, commercial products, and competition entries using documented search terms and inclusion criteria. Record similarities, differences, and claim revisions. This document supplies positioning discipline; it is not a novelty search or legal opinion.

## 8. Product proof points

A concise judge-facing proof sequence is: inspect separate thread manifests; observe the human critique before critic reveal; see a false critic item rejected; see a new human idea; inspect selective transfer; trace a retrieved prior decision into the reconstruction; compare V1 and Final by rubric and origin; and verify that only the human can finalize. This demonstrates the combined structure without overstating what one run proves.
